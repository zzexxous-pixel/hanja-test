# 📋 4급 한자 마스터 - 시스템 통합 개발자 가이드 (README.md)

본 플랫폼은 한국어문회 4급 배정한자(600자)를 효율적으로 학습하고, 웹 표준 기술을 활용하여 저사양 모바일/태블릿 환경에서도 끊김 없는 음성 인식 자가 테스트를 수행할 수 있도록 설계된 **Pure Vanilla JS 기반 모던 웹 애플리케이션**입니다.

## 🚀 1. 시스템 아키텍처 및 렌더링 최적화 엔진

구형 모바일 및 교육용 저사양 태블릿 환경에서의 끊김 없는 사용자 경험을 보장하기 위해 다음과 같은 고성능 브라우저 최적화 아키텍처를 구현하고 있습니다.

### 1) JIT & Prerender DOM Cache Engine

* **정적 페이지 선행 렌더링 (Prerender & Cache):** 애플리케이션 초기 가동 시 600자의 배정한자를 50자 단위로 분할하여 총 12개의 탭(1페이지~12페이지)으로 빌드합니다. 가상 DOM 구조를 미리 생성하여 `tabCache` 메모리 상에 상주시키고 관리합니다.
* **화면 고속 스왑 (No Re-parse):** 사용자가 페이지(탭)를 전환할 때마다 무거운 HTML 문자열을 재파싱하거나 실시간으로 DOM 노드를 신규 생성하지 않고, 사전에 캐싱된 DOM 노드를 물리적으로 통째로 덧붙여 교체(`appendChild`)합니다. 이를 통해 저사양 디바이스에서 흔히 발생하는 브라우저 프리징 현상을 원천 방어합니다.
* **북마크 지연 렌더링 (Bookmarks JIT with Dirty Flag):** 즐겨찾기 목록(★, 13번 가상 공간)은 매번 렌더링하지 않고 **더티 플래그(`isFavoritesDirty`) 패턴**으로 제어됩니다. 사용자가 별표를 토글할 때마다 `isFavoritesDirty = true`로 표시되며, 실제 즐겨찾기 탭 진입 시점에만 DOM을 선별 재컴파일하여 연산 낭비를 막습니다.
* **JIT 스팟 리셋 기전 (Just-In-Time Spot Reset):** 말하기 도전 모드를 해제할 때 화면 전체를 새로고침하는 대신, 현재 사용자가 보고 있는 활성 탭 하나만 즉각 초기화하고 나머지 보이지 않는 11개 탭은 `tabsNeedReset` 스케줄링 세트에 등록해 둡니다. 이후 사용자가 해당 탭에 진입하는 시점에 맞추어 **JIT(실시간)** 형태로 개별 초기화하여 CPU 오버헤드를 분산시킵니다.

### 2) 리플로우(Reflow) & 리페인트(Repaint) 원천 제어

* **레이아웃 격리 영역 지정 (Containment):** `.hanja-card-wrapper` 카드 컴포넌트 영역에 CSS 성능 최적화 지시어인 `contain: layout paint; content-visibility: auto;`를 부여하여 화면 스크롤 또는 탭 교체 시 브라우저가 전역 문서를 리플로우하지 않고 해당 영역 내부에서만 레이아웃을 다시 계산하도록 설계했습니다.
* **스크롤 떨림 방지 고정 렌더링:** `contain-intrinsic-size: 110px 150px;` 사양을 바인딩하여 브라우저 가상 스크롤 시 화면이 위아래로 심하게 흔들리는 레이아웃 점핑(Jumping) 현상을 정밀하게 방어합니다.
* **CSS 변수 기반 글꼴 크기 동적 조절:** 헤더의 폰트 크기 컨트롤러는 인라인 스타일 변경 대신, `:root`에 정의된 CSS 글로벌 변수(`--hanja-size`, `--hun-size`)를 수정하는 방식으로 리플로우를 단일 스레드 수준으로 제어하며, 이 변경값은 로컬 스토리지(`localStorage`)에 보존됩니다.
* **하드웨어 가속 힌트 기반 블러(Blur) 가림막:** 도전 모드 가동 시 적용되는 훈음 블러 필터(`.quiz-blur-target`)에 `will-change: filter; transform: translateZ(0);`를 이식하여 연산 처리를 CPU가 아닌 **GPU 하드웨어 가속** 영역으로 할당함으로써 저사양 기기에서도 극도의 시각적 부드러움을 유지합니다.

## 🛠️ 2. 핵심 기술 모듈 설계 명세

플랫폼은 기능의 응집도와 유지보수성을 극대화하기 위해 순수 자바스크립트 기반의 4대 독립 엔진 모듈로 파티셔닝되어 긴밀하게 연동됩니다.

```
📁 프로젝트 루트 폴더
├── 📄 index.html          # 단일 페이지 애플리케이션(SPA) UI 레이아웃 명세
├── 📄 style.css           # 성능 최적화 및 6단계 상태 머신 CSS 변수 통로
├── 📄 script.js           # UI 생명주기 관리, JIT 캐싱 제어 및 이벤트 디스패처
├── 📄 speechEngine.js     # 음성 수집 및 가비지 컬렉션(GC) 방어형 자모 유사도 채점 엔진
├── 📄 audioEngine.js      # Web Audio API 기반 오실레이터 주파수 합성 및 TTS 가이드
└── 📄 hanja_data.js       # 대한검정회 4급 배정 600자 데이터 표준 딕셔너리

```

### 1) UI 라이프사이클 및 브라우저 스토리지 연동 (`script.js`)

* 로컬 스토리지 데이터(`hanja_bookmarks`, `hanja_size`, `hun_size`)를 로드하여 사용자의 마지막 인터페이스 환경을 영구 복원합니다.
* 카드 클릭 시 동작 전역 가드인 `isCardLock`, `processingTargetIndex`, `evaluationTargetIndex` 상태 변수를 조합해 **이중 탭 발화 현상** 및 **연타 클릭 시 발생하는 음성 스트림 버퍼 충돌**을 완벽하게 격리 차단합니다.

### 2) 가비지 컬렉션(GC) 방어형 유사도 채점 엔진 (`speechEngine.js`)

* **한글 음소 분해 알고리즘 (`disassembleKorean`):** 입력받은 한국어 음성 텍스트의 유니코드 블록(44032 ~ 55203)을 정밀 분석해 초성/중성/종성 3차원 분해 구조를 완전 전개합니다.
* **공간 복잡도 O(N) Levenshtein Distance 연산:** 실시간 음성 프레임이 수집되는 동안 브라우저 내부에서 다량의 메모리 쓰레기가 발생해 가비지 컬렉터(GC)에 의한 화면 끊김(Stuttering)이 유발되는 것을 방어하기 위해, 기존의 대형 2차원 매트릭스 할당 방식을 기각하고 **단 2개의 1차원 행 배열(`prevRow`, `currRow`) 포인터만 스왑**하는 초고속 저용량 편집 거리 알고리즘을 이식했습니다.
* **실시간 패스 스킵 제어:** 음성이 인식 중일 때 수집되는 실시간 텍스트 조각(`interimResults`)을 연속적으로 대조하여, 사용자가 발화를 끝마치지 않았더라도 일치율이 정답 임계치를 도달하는 순간 즉시 합격(⭕) 판정을 내리고 오디오 세션을 Abort 함으로써 판정 민감도를 극대화했습니다.

### 3) Web Audio API 기반 사운드 신디사이저 (`audioEngine.js`)

무거운 사운드 미디어 파일(MP3, WAV 등)을 원격 서버에서 내려받거나 메모리에 복제 배치하지 않고, 브라우저가 직접 자생적인 주파수 발진기(`OscillatorNode`)와 볼륨 억제 기전(`GainNode`)을 활용하여 오프라인 상태에서도 0ms 즉시 재생 가능한 기계식 화음을 실시간 합성하여 출력합니다.

* **정답 성공음 (Correct Tone):**
* **구성 요소:** Sine 파형(기본 주파수)과 Triangle 파형(배음 주파수)의 듀얼 오실레이터 결합.
* **합성 원리:** 고음역대 C5(523.25Hz)에서 시작하여 메이저 3도 화음인 E5(659.25Hz) 및 G5(783.99Hz)로 기분 좋게 상승하는 아르페지오를 `exponentialRampToValueAtTime` 볼륨 감쇠 곡선(0.5초 지속)을 적용하여 청량감 있게 출력합니다.


* **오답 실패음 (Incorrect Tone):**
* **구성 요소:** Sawtooth 파형(톱니파)과 Biquad 필터 결합.
* **합성 원리:** 둔탁하고 거친 저음 주파수 130Hz 영역에 로우패스 필터(Lowpass Filter, 차단 주파수 1200Hz)를 융합 배치하여, 고막을 찌르지 않으면서도 단호하게 각성시키는 디지털 경고음을 자생 렌더링합니다.


* **Web Speech TTS 가이드:** `SpeechSynthesisUtterance` 인터페이스를 탑재하여 한국어 표준 훈음 음성 가이드를 아동 학습 피칭에 이상적인 `0.9 배속` 규격으로 제공합니다.

### 4) 실시간 인앱 개발자 디버그 터미널 (`index.html` & `script.js`)

* **이스터에그 트리거:** 헤더의 "4급 한자 마스터" 타이틀을 2.5초 이내에 연속 5회 타격하면 화면 하단에 고정 디버그 드로어(`#dev-console`)가 토글 표출됩니다.
* 시스템 부팅 로그, 사용자의 발화 감지 음성 분석 버퍼 현황, 편집 거리에 따른 정답 유사도 통계 매칭 백분율 데이터(`%`)를 현장에서 즉시 시각적으로 추적 모니터링할 수 있어 PC 디버깅 장비가 없는 태블릿 기기 자가 진단에 압도적 효율을 보장합니다.

## 🎙️ 3. 모던 PointerEvents 기반 자가 테스트 수집 프로토콜

클래식 모바일 웹의 터치 딜레이 및 하드웨어 가상화 간섭을 극복하기 위해 `PointerEvents` 기반의 실시간 6단계 상태 전환 머신을 수립하여 마이크 동작과 UI를 정밀 동기화합니다.

```
[State 1: idle]  ──(PointerDown)──> [State 2: touch] ──(Stream Open)──> [State 3: active]
      ▲                                                                         │
      │                                                                    (PointerUp)
(Reset / Next)                                                                  │
      │                                                                         ▼
[State 6: final] <──(Decision Correct/Incorrect)── [State 5: checking] <───────┘

```

### 1) 정밀 6단계 상태 머신 동작 요약

1. **State 1 (대기 - `idle`):** 기본 카드 상태로, 한자 크기와 일련번호(`#번호`)가 정상 노출됩니다.
2. **State 2 (연결 시도 - `touch`):** 카드를 누른 순간 실시간 서버 게이트와 물리 장비 채널 정렬을 시작하며 시각적으로 `⏳` 피드백이 점등됩니다.
3. **State 3 (수집 활성화 - `active`):** 마이크 권한이 활성화되고 구글 클라우드 오디오 스트림이 수립되어 펄스 애니메이션(`.mic-pulse-active`)이 구동되며 실시간 음성 수집을 시작합니다.
4. **State 4 (수집 중지 및 대기 - `stop`):** 사용자가 카드를 누르고 있다가 떼는 동작(`PointerUp`) 시 마이크 채널 닫힘 패킷이 전달됩니다.
5. **State 5 (실시간 채점 - `checking`):** 마이크 종료 후 즉시 펜슬 아이콘과 채점 펄스(`.checking-pulse-active`)가 돌입하며 **1.2초의 백업 만료 타이머**가 작동됩니다. (클라우드 세션 종료 가이드 패킷 분실 시 무한 로딩 상태에 빠져 카드가 얼어버리는 하드웨어 데드락을 원천 방어합니다.)
6. **State 6 (최종 판정 - `final`):** 알고리즘 대조 검사 결과에 따라 최종 정답(연두색 카드 및 `⭕`) 혹은 오답(주황색 카드 및 `❌`) 결과를 박제 출력합니다.

### 2) 안전 장치 및 인터럽트 차단 스펙

* **스크롤 오작동 감지 트래킹:** 손가락을 터치한 상태에서 최초 스펙 좌표 대비 10px 이상의 축 좌표 이동이 감지되면, 시스템은 사용자가 화면 스크롤을 원하고 있다고 즉각 감지하여 마이크 스트림을 자동 소멸 처리하고 탭 간섭을 무력화합니다.
* **수동 취소(Cancel) 인터럽트:** 사용자가 녹음 도중 카드를 한 번 더 탭하면 시스템은 사용자 변심으로 인지하고, 즉시 `speechEngine.cancel()` 및 `abort()`를 기동하여 스트림을 전면 파괴하고 최초 대기 상태(`#번호`)로 하드 리셋 환원합니다.

* 페이지네이션 버튼 클릭에 따른 실시간 `page-indicator` 상태 추적 및 별표 북마크 토글 시 13번 가상 공간(★) 탭으로 DOM 노드가 누락 없이 정교하게 생성 및 복제되는지 메모리 무결성을 확인합니다.


4. **시나리오 4: 말하기 도전 모드 활성화 및 블러 마스킹 시각 대조 검사**
* 도전 버튼 클릭 시 `theme-emerald` 테마 교체 여부를 추적하고 전체 한자의 훈음이 물리적으로 보이지 않는 CSS 블러로 강력 차단되는지 `02-quiz-mode-blur.png` 스냅샷으로 회귀 진단합니다. 또한 수동 해제(`.solved`) 기전의 물리 동작을 체크합니다.


5. **시나리오 5: Web Speech API 모킹을 이용한 실시간 정답 채점 패스 검증**
* 브라우저의 마이크 및 Speech API 하드웨어 드라이버를 완벽히 가로채는 가상 Mocking 레이어를 addInitScript 단계에 주입하여, 사용자가 가상으로 "값 가"라고 말했을 때 레벤슈타인 60% 역치를 돌파해 ⏳에서 `⭕` 마크로 원터치 변경되고 블러가 자율 해제되는지 전 과정을 시뮬레이션 검증합니다.


6. **시나리오 6: 헤더 타이틀 이스터에그 광속 타격 콘솔 팝업 검사**
* 헤더 영역을 2.5초 이내에 연속 5회 난사 터치했을 때 메모리 버퍼 용량 50라인 보존 규격을 갖춘 인앱 리얼타임 디버거 터미널(`#dev-console`)의 CSS display가 완벽히 온에어 상태로 기동되는지 확인합니다.

8. **시나리오 8: 음성 인식 실패 시 오답 피드백(❌) 및 블러 잠금 유지 검사**

## ☁️ 5. 지속적 통합 및 수동 배포 파이프라인 (CI/CD)

본 프로젝트는 테스트 저장소(`hanja-test`)와 진짜 운영 저장소(`hanja`)의 두 개 레포지토리를 완전 가로지르는 무결성 CI/CD를 탑재하여 소스코드의 파편화를 방지하고 고속 릴리즈 환경을 제공합니다.

```
[로컬 수정 / 웹 개발] ──(Push)──> [hanja-test 레포] ──(playwright.yml CI 가동)
                                                                 │
                                                    (10대 철벽 테스트 무결성 전수 검증)
                                                                 │
[정식 릴리즈 완료] <──(Force Push)── [배포 이관 완료] <──(통과 - Pass)

```

### 1) 무수정 100% 호환 자율 주소 바인딩 아키텍처

* `playwright.config.js` 설정 모듈은 하드코딩된 특정 타겟 도메인 주소를 철저히 배제하고, 가상 컴퓨터 실행 환경의 레포지토리 전역 변수(`process.env.GITHUB_REPOSITORY`)를 파싱하여 현재 구동 위치가 테스트 서버인지 본 서버인지 자율 인지합니다. 이에 따라 `baseURL`을 알아서 실시간 가변 조립하므로 코드 수정에 따른 인적 실수가 원천 차단됩니다.

### 2) 동적 의미론적 버전 명세 계산 (Semantic Automatic Versioning)

* `.github/workflows/deploy.yml` 파이프라인 엔진은 배포 직전 `VERSION` 명세 파일(예: `2.1`)을 판독한 뒤, 해당 파일이 최초 수정되었던 역사적 Git 해시 시점부터 현재 HEAD 커밋까지의 빌드 카운트(예: `15`)를 환산하여 패치 버전 번호를 실시간 합성해 냅니다.
* 테스트 저장소 배포 시에는 자동으로 `-test` 접미사를 붙여 `v2.1.15-test`로 릴리즈하고, 운영 이관 시에는 이 딱지를 떼어내어 완벽히 정식 `v2.1.15` 정적 버전을 정교하게 조립 주입하여 빌드합니다.

### 3) 원터치 운영 이관 수동 배포 워크플로우 (`deploy-to-prod.yml`)

* 개발자가 테스트 저장소 웹 액션즈 탭에서 🛠️ **[Run workflow]** 버튼을 탭하면 작동하는 초고속 운영 원격 파이프라인입니다.
* 가상 컨테이너 서버가 켜지면 곧바로 운영 서버에 덮어씌우지 않고, **Playwright 10대 철벽 시나리오 테스트를 리눅스 가상 환경에서 전수 재가동**합니다.
* **초고속 브라우저 캐싱 레이어:** 가상 리눅스 서버 내부에 플레이라이트 캐시 창고(`~/.cache/ms-playwright`)를 항시 개방하고 보존하여, 2회차 이관부터는 크롬 파일 다운로드를 건너뛰고 **단 3초 만에 런타임 환경 구성을 끝내고** 테스트에 돌입하여 총 30초 내외의 빠른 속도로 동기화를 이행합니다.
* **배포 가드:** 테스트 결과가 전부 초록불(Passed)일 때만 마스터 토큰키(`SYNC_TOKEN`) 보안 터널을 이용하여 운영 레포지토리(`hanja`)로 강제 푸시(`--force`) 이관하며, 단 하나의 예외 케이스라도 감지되어 실패(Failed)로 끝날 경우 즉시 이관 작업을 강제 폭파 취소(Abort)하고 운영 레포를 버그 파일 오염으로부터 절대 보호합니다.
